# Instruções permanentes do projeto

Antes de modificar o projeto, gerar artefatos ou criar commits, leia e siga
integralmente:

- `.agents/GIT_CONVENTIONS.md`
- `.agents/PROJECT_RULES.md`

As regras gerais de Git, commits e versionamento pertencem a
`.agents/GIT_CONVENTIONS.md`. As obrigações particulares deste projeto
pertencem a `.agents/PROJECT_RULES.md`.

Somente o proprietário do projeto pode alterar os números `x` e `y` de
`.agents/VERSION_PREFIX`. O Codex nunca deve alterar esse arquivo.

O `CHANGELOG.md` deve ser mantido conforme as regras de versionamento e
imutabilidade definidas em `.agents/GIT_CONVENTIONS.md`.
